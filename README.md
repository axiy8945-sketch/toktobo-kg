# ТОКТОБО KG

Кыргызстан үчүн китеп платформасы: онлайн окуу (PDF/EPUB), кагаз китепке заказ (MBank QR кол менен текшерүү же накталай), AI окуу коучу, окуу прогресси. Үч тилде: кыргызча, өзбекче, орусча.

**Стек:** Next.js 15 (App Router) · TypeScript · Tailwind CSS · Supabase (PostgreSQL, Auth, Storage, RLS) · Anthropic Claude (сервер тарабында) · PWA

---

## 1. Орнотуу (бир жолу)

### 1.1. Supabase долбоору
1. [supabase.com](https://supabase.com) сайтында жаңы долбоор ачыңыз. Регион катары **Frankfurt** же **Mumbai** ылайыктуу.
2. **SQL Editor** бөлүмүнө `supabase/schema.sql` файлын толук көчүрүп, **Run** басыңыз. Файлды кайра иштетсе да зыяны жок.
3. **Authentication → URL Configuration** бөлүмүндө:
   - *Site URL*: `http://localhost:3000` (кийин чыныгы домен)
   - *Redirect URLs*: `http://localhost:3000/auth/callback` жана `https://сиздин-домен.kg/auth/callback`
4. **Authentication → Providers → Email** иштетилген болсун (кирүү шилтеме аркылуу болот, сырсөз керек эмес).

### 1.2. Долбоорду иштетүү
```bash
npm install
cp .env.example .env.local     # анан маанилерди толтуруңуз
npm run dev                    # http://localhost:3000
```

`.env.local` файлы:
| Өзгөрмө | Кайдан алынат |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase → Project Settings → API |
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys |
| `ANTHROPIC_MODEL` | демейки `claude-sonnet-5-5` |
| `AI_DAILY_LIMIT` | бир колдонуучуга күнүнө AI суроо саны (демейки 60) |

> `service_role` ачкычы бул долбоордо **колдонулбайт**. Бардык коопсуздук RLS аркылуу камсыз кылынат.

### 1.3. Биринчи админ
1. Сайттан өз email'иңиз менен кириңиз.
2. Supabase SQL Editor'до төмөнкүнү иштетиңиз:
```sql
update public.profiles set role = 'admin'
 where id = (select id from auth.users where email = 'sizdin@email.kg');
```
3. Беттин жогорку оң бурчундагы ☰ менюдан **Админ панель** ачылат. Андан ары кызматкерлерди «Кызматкерлер» өтмөгүнөн дайындайсыз.

## 2. Кантип иштейт

### Китеп кошуу (админ → Китептер → Китеп кошуу)
- Мукаба сүрөтү `covers` бакетине жүктөлөт (ачык).
- Китеп файлы (PDF же EPUB, 100 МБ чейин) `books` бакетине жүктөлөт (жабык).
- Онлайн окуу режими: **Жок** / **Акысыз** / **Акылуу**. Кагаз нускасынын баасын бош калтырсаңыз, ал сатылбайт.

### Онлайн окуу доступу
| Китеп | Окурман эмне кылат | Доступ качан ачылат |
|---|---|---|
| Акысыз | «Акысыз ачуу» баскычын басат | Дароо |
| Акылуу | «Сатып алуу» → себет → заказ | Кызматкер «Төлөм келди — тастыктоо» баскычын басканда |
| Кол менен | — | Админ «Доступтар» бөлүмүнөн берет |

Файл браузерге 10 мүнөттүк убактылуу шилтеме аркылуу гана берилет (`/api/book-file/[id]`). Доступу жок адамга Storage шилтемени такыр түзбөйт (RLS).

### Заказ жана MBank QR
1. Кардар заказ берет. Баа серверде `place_order` функциясы аркылуу эсептелет, браузерден келген баага ишенилбейт.
2. Заказ «Админ → Заказдар» бөлүмүнө түшөт.
3. Кызматкер кардарга MBank QR-кодун жөнөтүп, **QR жөнөтүлдү** баскычын басат.
4. Төлөм келгенин MBank'тан кол менен текшерип, **Төлөм келди — тастыктоо** баскычын басат. Ушул учурда электрондук китептер автоматтык түрдө ачылат.

MBank менен автоматтык интеграция жок. Ал кийин `set_order_status` функциясына туташтырылса болот.

### Окуу статистикасы
Окуу режими ачык турганда ар 30 секундда `add_reading_seconds` чакырылат (бир чакырууда эң көп 120 сек). Серия, жума жана ай ушул маалыматтан эсептелет. Убакыт Бишкек саат алкагы боюнча эсептелет.

### AI коуч
`/api/coach` маршруту сервер тарабында иштейт, API ачкычы браузерге эч качан чыкпайт. Коуч колдонуучунун чыныгы статистикасын жана каталогду контекст катары алат. Күнүмдүк лимит `ai_usage` таблицасы аркылуу текшерилет.

## 3. Түзүм
```
supabase/schema.sql        таблицалар, RLS, RPC, Storage эрежелери
src/app/                   барактар (App Router)
  page.tsx                 башкы бет
  books/, books/[id]/      каталог жана китеп барагы
  cart/, orders/           себет, заказ берүү, заказ тарыхы
  library/, read/[id]/     менин китептерим, окуу режими (PDF/EPUB)
  coach/, api/coach/       AI коуч
  progress/                статистика, жетишкендиктер, максат
  admin/                   китептер, заказдар, доступтар, кызматкерлер
  login/, auth/callback/   email шилтеме менен кирүү
src/lib/                   Supabase клиенттери, i18n, статистика
src/components/            Header, TabBar, BookCard, Cover
public/sw.js, icons/       PWA
```

## 4. Жайгаштыруу (Vercel)
1. Долбоорду GitHub'га жүктөңүз да, Vercel'де **Import** басыңыз.
2. `.env.local` файлындагы өзгөрмөлөрдүн баарын Vercel → Settings → Environment Variables бөлүмүнө кошуңуз (`NEXT_PUBLIC_SITE_URL` = сиздин домен).
3. Supabase'тин *Redirect URLs* тизмесине `https://домен/auth/callback` кошуңуз.

## 5. Кийин кошула турган нерселер
- **Акы төлөнүүчү функциялар.** `entitlements.source` талаасына жаңы маани (мисалы, `subscription`) кошуу жетиштүү. Окуу доступу ошол бир `has_access()` функциясы аркылуу текшерилет.
- **Телефон менен кирүү (SMS).** Supabase Auth → Phone провайдерин иштетүү керек.
- **Аудиокитептер.** `books` таблицасына `audio_path` кошуп, `<audio>` ойноткуч жасалат (`playbackRate` менен ылдамдыкты 0.75–2× өзгөртсө болот).
